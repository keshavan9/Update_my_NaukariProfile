# Update_profile_everyday

This project automates the Naukri profile update flow with Playwright.

## Setup

1. Copy `.env.example` to `.env` and replace the placeholders with your actual Naukri credentials.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the suite:
   ```bash
   npx playwright test
   ```

Important: `.env` and generated test artifacts are ignored by git and should not be committed.
